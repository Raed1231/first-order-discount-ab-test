# اختبار خصم 10% لأول طلب

## الوصف
تطبيق متجر إلكتروني يدرس عرض خصم 10% على أول طلب للمستخدمين الجدد. تساعد التجربة على قرار واحد: هل نطلق الخصم لجميع المستخدمين الجدد، أم نبقي الأسعار بدون خصم؟

## السؤال والفرضية
- القرار: هل نطلق «خصم 10% على أول طلب» لجميع المستخدمين الجدد؟
- الفرضية: إذا عرضنا خصم 10% على أول طلب للمستخدم الجديد، فسوف ترتفع نسبة المستخدمين الذين يُتمّون طلبًا، لأن المستخدم الجديد متردد في أول تجربة شراء، والخصم يخفض المخاطرة التي يشعر بها ويعطيه سببًا للشراء الآن.

## التصميم
- وحدة العشوائية: المستخدم الجديد (معرّف الحساب)، بتوزيع 50% / 50%.
- المقياس الرئيسي ومقاييس الحماية: المقياس الرئيسي هو نسبة الطلب. مقاييس الحماية هي الربح لكل مستخدم بعد تكلفة الخصم، ونسبة إلغاء الطلبات، والتواصل مع الدعم.
- حجم العينة والمدة: 14,749 مستخدمًا في كل مجموعة لاكتشاف أثر بنقطة مئوية واحدة (من 10% إلى 11%) بقوة 80% ومستوى دلالة 5%. المدة 7 أيام (أسبوع كامل)، وأصغر أثر قابل للاكتشاف فيها حوالي 0.90 نقطة.

## النتائج والتوصية
- الأثر الرئيسي وفترة الثقة: يُكتب يوم الثلاثاء (اليوم الثالث) بعد التحليل.
- التوصية: تُكتب يوم الأربعاء (اليوم الرابع).
